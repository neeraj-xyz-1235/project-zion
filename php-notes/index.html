PHP: Notes

Built from the PHP unit slides. Each topic has a definition, an explanation with rules, the syntax, a short demo program with output, and extras such as comparison tables and tips.

Unit 1 · Introduction to PHP

Features, advantages, syntax, the 8 data types, var_dump(), variables and scope, $$, constants, all operator types, comments, echo and print.

Unit 2 · Control, Functions & Arrays

if / elseif / nested if, switch, for, foreach, while, do-while, break and continue, functions (default, variadic, recursive, by reference), arrays, array and string functions.

Unit 3 · Object-Oriented PHP

Class, object, $this, constructors, destructor, inheritance types, abstract classes, interfaces, polymorphism, encapsulation and access modifiers, final.

How each topic is laid out

The highlighted box is the definition. Learn it as written for exam answers.
Green boxes are memory tips.

not in slides means something was added because it's commonly asked in exams but isn't on the slides.

Yellow notes point out mistakes in the slides, with the correct version alongside.

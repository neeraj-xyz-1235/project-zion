Unit 1: Introduction to PHP

What PHP is, its features, syntax, data types, variables and scope, constants, operators, comments and output with echo and print.

1Introduction to PHP

PHP stands for "PHP: Hypertext Preprocessor". It is a widely used, open-source, general-purpose, server-side scripting language, especially suited to web development, that can be embedded into HTML.

Key facts

  • Created by Rasmus Lerdorf in 1994, released to the public in 1995.
  • The slides list PHP 8.4.12 as the latest version.
  • PHP scripts run on the server. The browser only receives the HTML output.
  • It supports many databases: MySQL, Oracle, PostgreSQL, Informix, Sybase, Solid, Generic ODBC and others.
  • It runs on many platforms (Windows, Linux, Unix, macOS) and works with almost all servers (Apache, IIS, Nginx).
  • It's free to download from www.php.net, easy to learn and efficient on the server.
Remember: PHP is a recursive acronym: the "P" in PHP stands for PHP itself.

3Advantages of PHP

  • Cross-platform: works on Mac, Windows and Linux.
  • Easy to learn, even for complete beginners.
  • Works with all databases: relational and non-relational (MySQL, PostgreSQL, MongoDB).
  • Open source: anyone can contribute, which is part of why frameworks like Laravel are popular.
  • Friendly community and official documentation.
  • Multi-paradigm: supports procedural, imperative, functional and object-oriented styles.
  • Integrated with HTML: used for dynamic content, database work, session tracking and even whole e-commerce sites.

6PHP Syntax

A PHP file can contain HTML tags and PHP code together. All PHP code goes between the tags <?php and ?>.

Rules

  • Save the file with the .php extension.
  • Every PHP statement ends with a semicolon (;).
  • Code starts with <?php and ends with ?>.
  • Keywords, function and class names are not case-sensitive, but variable names are.not in slides

7PHP Data Types

PHP supports 8 primitive data types, grouped into 3 categories: Scalar (predefined), Compound (user-defined) and Special.
PHP data types (8) ├── Scalar (4) → boolean, integer, float, string ├── Compound (2) → array, object └── Special (2) → resource, NULL

8Scalar Types

1. Boolean

The simplest type. It works like a switch and holds only TRUE (1) or FALSE (0). Often used in conditions.

2. Integer

A whole number (no decimal point), positive or negative.
  • Can be positive or negative.
  • Must not contain a decimal point.
  • Can be written in decimal (base 10), octal (base 8, prefix 0), hexadecimal (base 16, prefix 0x) or binary (prefix 0b).
  • Range on 32-bit systems: −2,147,483,648 to 2,147,483,647 (−231 to 231 − 1).
The slide gives the range as "−2^31 to 2^31". The upper limit is 231 − 1. On today's 64-bit systems, PHP integers actually go up to PHP_INT_MAX = 263 − 1.

3. Float (double)

A number with a decimal point or fractional part, positive or negative.

4. String

A sequence of characters (letters, numbers, special characters), written in single or double quotes.
Double quotes " "Single quotes ' '
Variables inside are replaced with their values (parsed)Content is taken literally, so variables are not parsed
Escape sequences like \n workOnly \' and \\ work

9Compound Types

1. Array

An array stores multiple values in a single variable.
The slide says an array stores values "of the same data type". PHP arrays can actually hold mixed types, e.g. array(1, "two", 3.0). Unit 2's slides say so too.

2. Object

An object is an instance of a user-defined class that stores both values (properties) and functions (methods).

10Special Types

1. Resource

A resource is a special variable that holds a reference to an external resource, not an actual value.

Examples: file handles, database connections, URL sessions, image objects.

2. NULL

NULL means a variable has no value. It has only one possible value: NULL. By convention it's written in capitals.

11var_dump() Function

var_dump() is a built-in function that dumps information about variables: their data type and value. For strings it also shows the length.
var_dump(var1, var2, ...);
  • Parameter: one or more variables or values to dump.
  • Return: nothing. It prints the result directly.
Output
int(25) float(32.5) bool(true)
The slide's output leaves out the middle line, float(32.5).

More examples

var_dump(5); → int(5) var_dump("John"); → string(4) "John" var_dump(3.14); → float(3.14) var_dump(true); → bool(true) var_dump([2, 3, 56]); → array(3) { [0]=> int(2) [1]=> int(3) [2]=> int(56) } var_dump(NULL); → NULL

12Variables

A variable is a named region of memory that holds data. In PHP it starts with a $ sign. PHP is dynamically typed, so the type is inferred from the value.
  • There's no command to declare a variable. It's created when you first assign a value.

Rules for variable names

  • Starts with $, followed by the name.
  • The name must start with a letter or underscore, never a number.
  • It can contain only letters, numbers and underscores (A–z, 0–9, _).
  • Names are case-sensitive: $age and $AGE are different.
Valid: $name, $_total, $age2 · Invalid: $2age, $my-name, $my name

13Variable Scope

The scope of a variable is the part of the script where it can be used. PHP has three scopes: local, global and static.

1. Global scope

A variable declared outside a function has global scope. It can only be used outside functions.

The global keyword

To use a global variable inside a function, declare it with global:

The $GLOBALS['x'] array does the same job.not in slides

2. Local scope

A variable declared inside a function exists only within that function.

3. Static scope

Normally a function's local variables are deleted when it finishes. A static variable keeps its value between calls, but is still local to the function.

15Constants

A constant is a name for a value that can't be changed or undefined while the script runs. Once defined, it stays the same across the whole program.

Characteristics

  • Follows the same naming rules as variables, but has no $ sign.
  • By convention, written in UPPERCASE.
  • Constants are automatically global and can be used inside functions without global.
  • Two ways to define one: define() and the const keyword.

22Logical Operators

Logical operators combine conditions and return true or false.
The slide says logical operators "perform bit-level operations". That sentence was copied from the bitwise slide by mistake. Logical operators work on true/false conditions, not bits.
OperatorNameTrue when
&& or andANDBoth are true
|| or orORAt least one is true
!NOTThe operand is false
xorXORExactly one is true, not both

&& and and do the same thing but have different precedence: && binds more tightly. The same goes for || and or.

On the slide, the !$a example prints "a is true" in the wrong branch (the messages are swapped), and it uses ^ (bitwise XOR) where it means the logical xor.

24Comments

Comments are notes in the code that aren't executed. They explain code to other developers (or to you later), and can temporarily hide code while debugging.

Types

  • Single-line: // comment (C++ style) or # comment (Unix shell / Perl style).
  • Multi-line: /* ... */ (C style).

25echo Statement

echo is a language construct (statement) used to display output: strings, multi-line strings, variables, escaped characters and HTML.
void echo ( string $arg1 [, string $... ] )

Characteristics

  • Can be used with or without parentheses: echo or echo().
  • Returns no value.
  • Can take multiple strings separated by commas.
  • Faster than print.

26print Statement & print_r()

print is also a language construct that displays output, like echo. It always returns 1, so it can be used inside expressions.
int print ( string $arg )

Characteristics

  • Parentheses are optional: print "Hi"; and print("Hi"); are both valid.
  • Always returns 1.
  • Takes only one argument.
  • Slower than echo.

Printing arrays: print_r()

print and echo can't print a whole array. Use print_r(), or print one element at a time.

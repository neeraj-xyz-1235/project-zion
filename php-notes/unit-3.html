Unit 3: Object-Oriented Programming in PHP

Classes and objects, $this, constructors and destructors, inheritance, abstract classes and interfaces, polymorphism, encapsulation and the final keyword.

1OOP Conceptsnot in slides

Object-Oriented Programming (OOP) organises a program around objects, which bundle data (properties) and behaviour (methods), instead of around functions alone.

2Class

A class is a blueprint or template that defines the properties (variables) and methods (functions) its objects will have.
  • Declared with the class keyword, then the class name and curly braces.
  • Example: Car is a class. Mercedes, BMW and Audi are objects made from it.
  • Class = the idea or design. Object = the real thing built from it.
class MyClass { // properties and methods }

3Object

An object is an instance of a class: a real entity created from the blueprint with the new keyword.

Characteristics

  • Contains data and behaviour: the properties and methods defined in the class.
  • Has its own memory: each object gets its own copy of the properties, but methods are shared.
  • Arrow operator (->): used to access properties and methods: $obj->name, $obj->show().

Demo: class with a property and a method

4$this Keyword

$this is a special variable that refers to the current object. Inside a class, it's used to access that object's own properties and methods.

Without $this: wrong

With $this: correct

Rules

  • $this->property reads or changes a property.
  • $this->method() calls another method of the same class.
  • $this can't be used in static methods, because they belong to the class, not to an object.

5Constructor

A constructor is a special method named __construct() that is called automatically when an object is created with new. It sets up the object's initial state.
__construct(mixed ...$values = ""): void

Characteristics

  • Runs automatically, so you never call it yourself.
  • Used to set default property values, open database connections and do other setup.
  • Optional: a class doesn't have to have one.
  • Can take any number of parameters, and returns no value.
Output
The class PHP was initiated!

__CLASS__ is a magic constant that gives the current class name.

Default constructor setting values

Drawback: every object gets the same brand and price. A parameterised constructor fixes that.

6Parameterised Constructor

A constructor that takes arguments, so each object can be created with its own values.
Output
Brand: Toyota Price: 15000 Brand: Honda Price: 18000

7Overloading the Constructor

Constructor overloading means having several constructors with different numbers of parameters. PHP doesn't support it. The workaround is to give parameters default values.
Output
Brand: Toyota, Price: 15000 Brand: Honda, Price: 0 Brand: Unknown, Price: 0

8Type Declarations in the Constructor

Since PHP 7.0, parameters can declare scalar types (string, int, float, bool). Since 7.4, properties can be typed too. Passing the wrong type causes an error.

9Destructor

A destructor is a special method named __destruct() that is called automatically when an object is destroyed: when no references to it remain, or the script ends. It's used to clean up and free resources.
__destruct(): void

Characteristics

  • Optional, but advisable when the constructor acquires resources.
  • Never called directly. PHP's garbage collector triggers it.
  • Takes no parameters.
  • A class has only one destructor, and it can't be overloaded.
Output
Constructor is called. Object of class CleanupDemo is being destroyed.

Advantages

  • Frees memory for new objects.
  • Handles cleanup, so tasks run efficiently.
  • Prevents memory leaks when many objects and structures are created.

10Inheritance

Inheritance lets a class (the child) inherit properties and methods from another class (the parent), using the extends keyword. It promotes code reuse and builds a class hierarchy.
  • Parent (base / super) class: the class being inherited from.
  • Child (derived / sub) class: the class that inherits. It can add new methods or override existing ones.
  • The child inherits public and protected members, not private ones.
class ChildClass extends ParentClass { // inherits public and protected members }

Types in PHP

Single Multilevel Hierarchical A A A │ │ ┌───┴───┐ B B B C │ C
PHP doesn't support multiple inheritance of classes (one class extending two). It gets the same effect through interfaces (a class can implement many) and traits.not in slides

11Single Inheritance

Single inheritance: one child class inherits from one parent class.

Example: Shape → Trapezoid

12Multilevel Inheritance

Multilevel inheritance: a class inherits from a child class, which itself inherits from another class. That's a chain: grandparent → parent → child. The last class can use the methods of all its ancestors.

13Hierarchical Inheritance

Hierarchical inheritance: several child classes inherit from the same parent class. Each child gets the shared functionality and adds its own.

14Abstract Classes

An abstract class is a blueprint for other classes, declared with the abstract keyword. It can't be instantiated, and it can contain abstract methods (declared, with no body) that child classes must implement.

Characteristics

  • Can't create an object of it: new MyClass gives a fatal error.
  • Can contain abstract methods (no body) and normal methods (with a body).
  • Child classes must override all abstract methods.
  • If a class has even one abstract method, the class itself must be declared abstract.
abstract class MyClass { abstract public function absMethod($arg1, $arg2); // no body public function normalMethod() { echo "Hello"; } // with body }

Errors

$obj = new MyClass; → Fatal error: Cannot instantiate abstract class MyClass class myclass { abstract function absmethod(); } // not declared abstract → Fatal error: Class myclass contains 1 abstract method and must therefore be declared abstract

Why use abstract classes?

  • Code reusability: shared properties and methods are written once in the base.
  • Enforcing structure: every child must implement certain methods.

15Interfaces

An interface is a collection of method declarations (no bodies) that sets the rules a class must follow. It's declared with the interface keyword, and a class uses it with implements.

Characteristics

  • All methods are public and abstract by default, with no implementation.
  • It can't have properties (variables), only constants.
  • A class that implements an interface must implement all its methods.
  • A class can implement multiple interfaces, which is how PHP gets multiple inheritance.
  • Used to enforce common behaviour across unrelated classes.
interface InterfaceName { public function method1(); public function method2($arg); }

17Polymorphism

Polymorphism comes from the Greek poly (many) + morph (forms), meaning "many forms". In OOP, different classes can use the same method name but behave differently depending on which object calls it.
  • One of the four pillars of OOP.
  • Makes code flexible, reusable and maintainable.

Types

18Method Overriding

Method overriding is when a child class provides its own version of a method that already exists in the parent, with the same name and parameters. Calling it on a child object runs the child's version.

20Encapsulation

Encapsulation is wrapping data (properties) and methods together into a single unit (the object), and hiding the internal data from outside interference.

Characteristics

  • Keeps data and code safe from outside interference.
  • A class can change its internal implementation without affecting the rest of the system.
  • Implemented in PHP with the access modifiers public, private and protected.
  • Private data is reached only through public getter and setter methods, which gives controlled access.

Members are public by default and can be accessed from anywhere.

Remember: public = everyone · protected = family (class + children) · private = only me (the class).

22final Keyword

The final keyword prevents changes through inheritance. A final class can't be extended, a final method can't be overridden, and (from PHP 8.1) a final constant can't be overridden.

1. final class

A final class can't be inherited. Use it when a class must not be changed or extended.

Fatal error: Class SubClass cannot extend final class MainClass

2. final method

A final method can't be overridden in a child class, although the class itself can still be extended.

Fatal error: Cannot override final method BaseClass::calculate()

3. final constant (PHP 8.1+)

Fatal error: CustomSettings::VERSION cannot override final constant AppSettings::VERSION
Applied toEffect
ClassCan't be extended
MethodCan't be overridden (the class can still be extended)
Constant (8.1+)Can't be overridden in a child class
PHP doesn't allow final on properties (unlike Java). Use readonly (PHP 8.1+) for values that shouldn't change.not in slides

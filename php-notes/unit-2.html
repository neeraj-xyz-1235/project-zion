Decision making, loops, break and continue, user-defined functions with all their argument styles, recursion, arrays and common array and string functions.

1Decision Making in PHP

PHP makes decisions with the if, elseif and else keywords (language constructs). They run different code depending on whether a condition is true or false.

Forms of the if statement

  1. if: run code only if a condition is true.
  2. if-else: one block if true, another if false.
  3. if-elseif-else: check several conditions in turn.
  4. nested if: an if inside another if.

Plus switch, which checks one variable against many values.

2if Statement

The if statement runs its block only if the condition is true.
if (condition) { // code to be executed }
Output
12 is less than 100

3if-else Statement

The if-else statement runs one block if the condition is true and another block if it's false.
if (condition) { // code if true } else { // code if false }
Output
12 is even number

4if-elseif-else Statement

The if-elseif-else ladder combines several if-else statements to check multiple conditions one after another. The first true condition's block runs, and if none are true, the else block runs.
if (condition1) { // if condition1 is true } elseif (condition2) { // if condition2 is true } else { // if all conditions are false }
Output
B grade
The slide's version checks $marks < 33 then $marks >= 34, so marks of exactly 33 fall through to "Invalid input". It also uses < 100, so 100 is "Invalid" too. The version above fixes both by letting each check follow on from the one before.

5Nested if Statement

A nested if is an if block inside another if block. The inner if runs only when the outer condition is true.
if (condition1) { if (condition2) { // runs only if both are true } }
Output
Eligible to give vote

6switch Statement

The switch statement tests one variable or expression against many values (cases). It replaces a long if-else chain and makes code easier to read.
switch (expression) { case value1: // code break; case value2: // code break; default: // code if no case matches }

Rules

  • default is optional, and there can be only one. More than one gives a fatal error. It's usually written last.
  • break ends a case. Without it, execution falls through into the following cases.
  • The expression can be a number, character, string or function call.
  • Switches can be nested, but that makes code harder to read.
  • A semicolon (;) can be used instead of the colon (:) after a case.
Output
Number is equal to 20

7for Loop

The for loop repeats a block a fixed number of times. Use it when you know how many iterations you need. Initialisation, condition and update are all written in one place.
for (initialization; condition; increment/decrement) { // code to be executed }
  • Initialisation: sets the counter. It runs only once, and is optional.
  • Condition: checked before every iteration. The loop continues while it's TRUE.
  • Increment/decrement: updates the counter after each iteration.

Programs

8Nested for Loop

A nested for loop is a for loop inside another for loop. The inner loop runs completely for every single iteration of the outer loop.

If the outer loop runs 3 times and the inner loop 3 times, the inner body runs 3 × 3 = 9 times.

9foreach Loop

The foreach loop is the easiest way to go through every element of an array (or object). It needs no counter or increment.
  • Works only on arrays and objects. Any other type gives an error.
foreach ($array as $value) { // code } foreach ($array as $key => $value) { // code (key and value) }
Output
Season is: summer Season is: winter Season is: spring Season is: autumn

10while Loop

The while loop repeats a block as long as the condition is TRUE. Use it when the number of iterations isn't known in advance.
  • It's an entry-controlled loop: the condition is checked before the body runs. If it starts false, the body never runs.
while (condition) { // code } // alternative syntax while (condition): // code endwhile;

11do-while Loop

The do-while loop runs the body first and checks the condition afterwards, so the body is guaranteed to run at least once. It's an exit-controlled loop.

13break Statement

break immediately ends the current loop (for, while, do-while, foreach) or switch. Control moves to the first statement after it.
  • Inside a nested loop, break ends only the inner loop.
Output
Number: 1 Number: 2 Number: 3 Number: 4 Reached 5, breaking the loop.

14continue Statement

continue skips the rest of the current iteration and jumps straight to the next one. The loop itself keeps running.
  • Works with for, while, do-while and foreach.

15Functions

A function is a self-contained block of code that performs a specific task. It can take inputs (parameters), run statements and optionally return a value.

Types

  • Built-in (library) functions: already provided by PHP, e.g. var_dump(), fopen(), print_r(), gettype(), strlen().
  • User-defined functions: written by the programmer.

Advantages

  • Code reusability: define once, call many times.
  • Less code: the logic isn't repeated.
  • Easy to understand: the program is split into logical pieces.

16User-defined Functions

A user-defined function is created with the function keyword, followed by a name and parentheses.
function functionName() { // code to be executed }

Rules

  • Start with the keyword function.
  • The name must start with a letter or underscore, not a number.
  • Call it by writing its name and parentheses: functionName();
  • Function names are not case-sensitive.not in slides

Parameterised functions

A function can take any number of parameters, separated by commas. A parameter can be a scalar (number, string, boolean), an array, an object or even a function.

Returning values

The return keyword sends a value back to the caller and ends the function. Any type can be returned, including arrays and objects.

18Type Mismatch in Arguments

PHP converts types automatically, but some combinations fail.

Case 1: adding two non-numeric strings causes an error

Result: TypeError: Unsupported operand types: string + string, because PHP can't add text numerically.

Case 2: concatenating a string and a number works

Remember: + means numeric addition and . means string joining. PHP converts numbers to strings automatically when concatenating.

19Default Argument Values

A parameter can have a default value, set with =. If no argument is passed for it, the default is used. This cuts down on conditional checks and makes functions more flexible.
function functionName($param1 = defaultValue, $param2 = anotherValue) { // body }

Rules

  1. Defaults must be constant expressions (a string, number, array). Variables and function calls aren't allowed.
  2. Default parameters come after non-default ones.

20Variable Length Argument Functions

A variable-length argument (variadic) function accepts 0, 1 or any number of arguments. Put three dots (...), the spread operator, before the parameter name. It's available since PHP 5.6.
  • All the extra arguments are packed into an array inside the function.
  • Useful when the number of inputs isn't known in advance.
function functionName(...$arguments) { // $arguments is an array }

21Recursive Functions

Recursion is when a function calls itself. Every recursive function needs a base case, a condition that stops the recursion. Without one it calls itself forever, until memory runs out.

How it works

  1. The calling code calls the recursive function.
  2. The function does some processing.
  3. If the base case isn't reached, it calls itself again, creating a new instance.
  4. When the base case is reached, it returns, and the calls unwind back to the caller.

Trace

factorial(5) = 5 * factorial(4) = 5 * (4 * factorial(3)) = 5 * (4 * (3 * factorial(2))) = 5 * (4 * (3 * (2 * factorial(1)))) = 5 * 4 * 3 * 2 * 1 = 120

22Pass by Value vs Pass by Reference

Pass by value (default)

A copy of the variable is passed. Changes inside the function don't affect the original variable.

Pass by reference (&)

Put an ampersand (&) before the parameter. The function works on the original variable, so changes inside do affect it outside.
Pass by valuePass by reference
A copy is passedThe original variable is passed (&$x)
The original stays unchangedThe original is modified
Safer, and the defaultUseful when the function must update the caller's variable

23Arrays

An array is a data structure that stores multiple values in a single variable. Each value is identified by a key (index) used to access, change or process it.

Uses

  • Data storage: related data in one place.
  • Data processing: easy to loop over and manipulate.
  • Flexibility: can hold different types (integers, strings, objects).

Advantages

  • Less code: one array instead of many variables.
  • Easy to traverse with loops.
  • Easy to sort with built-in functions.
  • Dynamic size: grows automatically as items are added.
  • Data grouping: related data is easier to find.

26Multidimensional Arrays

A multidimensional array is an array containing one or more arrays as its elements. It stores data in rows and columns (or more dimensions), like a table or matrix.
  • One-dimensional: a simple list.
  • Two-dimensional: an array of arrays (rows × columns).
  • Elements are accessed with multiple indexes: $array[row][column].
Output
1 Sam 400000 2 John 500000 3 Rick 300000 John

27Array Functions

PHP has many built-in array functions for accessing and manipulating array elements. They work on single and multidimensional arrays.

array()

Creates and returns an array: indexed, associative or multidimensional.

array array ([ mixed $... ])

array_push()

Adds one or more items to the end of an array. The array is passed by reference, so the original is changed. It returns the new number of elements.

array_push(array &$array, mixed ...$values): int

array_pop()

Removes and returns the last element. The array shrinks by one. Returns NULL if the array is empty.

array_pop(array &$array): mixed

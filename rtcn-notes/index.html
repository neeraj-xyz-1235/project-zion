RTCN: Notes

Built from the RTCN unit PDFs. Each topic has a definition, an explanation (characteristics and sub-components), and extras such as header diagrams, worked examples, comparisons and memory tips.

Unit 1 · Internet & IP Addressing

Structure of the Internet, intranet, ISP, ICANN, IPv4 and IPv6 headers, classful and classless addressing, subnetting, masking, supernetting, ARP, RARP.

Unit 2 · Routing

Routers, hub vs switch vs router, router architecture, routing tables, static vs dynamic routing, routing algorithms, RIP, OSPF, EIGRP, BGP.

Unit 3 · Transport Layer & SCTP

Ports and sockets, multiplexing, TCP header and handshakes, flow and congestion control, UDP, DCCP and QUIC, and SCTP's services, features, packet format and chunks.

Unit 2.3: Java Database Connectivity (JDBC)

How a Java program connects to a database, runs SQL and reads the results.

1JDBC: Introduction

Definition

JDBC (Java Database Connectivity) is a Java API for connecting to a database, executing queries and processing the results.

Description

  • It is part of Java SE (Standard Edition). Its classes and interfaces are in the java.sql package.
  • The JDBC API uses JDBC drivers to talk to the database.
  • It can access tabular data in any relational database to save, update, delete and fetch data.
  • It works like Microsoft's ODBC (Open Database Connectivity).
  • The current version is JDBC 4.3, stable since 21 September 2017.
  • It is based on the X/Open SQL Call Level Interface (CLI), a standard for calling SQL that keeps applications portable across database vendors.
Java Application ──▶ JDBC API ──▶ JDBC Driver ──▶ Database

2Why Should We Use JDBC?

  • Before JDBC, the ODBC API was used to connect to databases. ODBC drivers are written in C, so they are platform-dependent and unsecured.
  • Java therefore defined its own API (JDBC) with drivers written in Java.

With JDBC you can:

  • Connect to the database.
  • Execute queries and update statements.
  • Retrieve the results returned by the database.

Extra features

  • Metadata: DatabaseMetaData gives information about tables, columns and indexes. This is useful for building SQL queries dynamically.
  • Batch processing: groups several SQL statements and runs them together, which cuts round trips to the database and improves performance.

4JDBC Drivers and Types

Definition

A JDBC driver is a software component that lets a Java application interact with a database. There are 4 types.

Type 1: JDBC-ODBC Bridge Driver

  • Uses an ODBC driver to connect to the database. It converts JDBC method calls into ODBC function calls.
  • It is now discouraged because the thin driver is better. Oracle does not support it from Java 8.
Java App → JDBC API → JDBC-ODBC Bridge → ODBC Driver → Database

Advantages: easy to use, and can connect to any database.
Disadvantages: slow, because every JDBC call is converted to an ODBC call. The ODBC driver must be installed on the client machine.

Type 2: Native-API Driver (partially Java)

  • Uses the database's client-side libraries. It converts JDBC calls into native calls of the database API, which the database understands directly.
  • It is not written entirely in Java.
Java App → JDBC API → Native-API Driver → Vendor Client Library (C/C++) → Database

Advantage: better performance than Type 1.
Disadvantages: the native driver and the vendor's client library must be installed on every client machine.

Type 3: Network Protocol Driver (fully Java)

  • Uses middleware (an application server) that converts JDBC calls, directly or indirectly, into the vendor-specific database protocol.
  • It is fully written in Java.
Java App → JDBC API → Network Driver → Middleware (App Server) → Database

Advantage: no client-side library needed. The application server can handle auditing, load balancing, logging and so on.
Disadvantages: needs network support on the client, and database-specific coding in the middle tier, which makes it costly to maintain.

Type 4: Thin Driver (fully Java)

  • Converts JDBC calls directly into the vendor-specific database protocol, which is why it is called "thin".
  • It is fully written in Java, and it's the most widely used today.
Java App → JDBC API → Thin Driver → Database

Advantages: best performance of all four types. No software needed on the client or server side.
Disadvantage: the driver depends on the database.

5Steps to Connect a Database in Java

There are 5 steps:

Step 1: Register the driver class

The forName() method of the Class class loads the driver class dynamically.

public static Class forName(String className) throws ClassNotFoundException
Class.forName("oracle.jdbc.driver.OracleDriver");

Step 2: Create the connection

The getConnection() method of DriverManager opens the connection.

public static Connection getConnection(String url) throws SQLException public static Connection getConnection(String url, String name, String password) throws SQLException
Connection con = DriverManager.getConnection(
        "jdbc:oracle:thin:@localhost:1521:xe", "system", "password");

Step 3: Create the statement

The createStatement() method of Connection creates a Statement, which executes queries.

public Statement createStatement() throws SQLException
Statement stmt = con.createStatement();

Step 4: Execute the query

The executeQuery() method of Statement runs the query and returns a ResultSet holding the records.

public ResultSet executeQuery(String sql) throws SQLException
ResultSet rs = stmt.executeQuery("select * from emp");
while (rs.next()) {
    System.out.println(rs.getInt(1) + " " + rs.getString(2));
}

Step 5: Close the connection

Closing the connection also closes its Statement and ResultSet automatically.

public void close() throws SQLException
con.close();

6Example: Connect Java with Oracle

What you need to know

ItemValue
Driver classoracle.jdbc.driver.OracleDriver
Connection URLjdbc:oracle:thin:@localhost:1521:xe
Usernamesystem (default)
PasswordThe one set when Oracle was installed

URL breakdown

jdbc = API · oracle = database · thin = driver · localhost = server name (or IP) · 1521 = port · xe = Oracle service name. You can find all of these in the tnsnames.ora file.

Create the table first

create table emp(id number(10), name varchar2(40), age number(3));

Program

import java.sql.*;

class OracleCon {
    public static void main(String[] args) {
        try {
            // 1. load driver
            Class.forName("oracle.jdbc.driver.OracleDriver");
            // 2. connect
            Connection con = DriverManager.getConnection(
                    "jdbc:oracle:thin:@localhost:1521:xe", "system", "oracle");
            // 3. statement
            Statement stmt = con.createStatement();
            // 4. execute query
            ResultSet rs = stmt.executeQuery("select * from emp");
            while (rs.next())
                System.out.println(rs.getInt(1) + " " + rs.getString(2) + " " + rs.getString(3));
            // 5. close
            con.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }
}

Loading the jar file (ojdbc14.jar)

  1. Paste it into the JRE/lib/ext folder, or
  2. Set the classpath:
    • Temporary: C:>set classpath=c:\folder\ojdbc14.jar;.;
    • Permanent: Environment Variables → New → name classpath, value ...\ojdbc14.jar;.;
The jre/lib/ext folder was removed in Java 9. On modern Java, use the classpath: java -cp ".;ojdbc14.jar" OracleCon.

8DriverManager Class

Definition

DriverManager (in java.sql) acts as an interface between the user and the drivers. It keeps track of the available drivers and sets up the connection between a database and the right driver.

  • It keeps a list of Driver classes that registered themselves with DriverManager.registerDriver().
  • A driver must be registered before you use the database, otherwise an exception is thrown.

Methods

MethodDescription
static synchronized void registerDriver(Driver d)Registers the driver. Does nothing if it's already registered.
static synchronized void deregisterDriver(Driver d)Removes the driver from the list.
static Connection getConnection(String url)Connects to the given URL. Throws SQLException if no matching driver is registered.
static Connection getConnection(String url, String user, String pwd)Connects with a URL, username and password.
static Connection getConnection(String url, Properties prop)Connects using a Properties object that holds the username and password.
static Driver getDriver(String url)Returns a registered driver that understands the URL.
static int getLoginTimeout()Returns the maximum time a driver may wait to connect.
static void setLoginTimeout(int sec)Sets that time in seconds. 0 means wait forever.

9Connection Interface

Definition

A Connection is a session between a Java application and a database.

  • It is a factory for Statement, PreparedStatement and DatabaseMetaData objects.
  • It provides transaction-management methods: commit(), rollback(), setAutoCommit() and setTransactionIsolation().
  • By default, it auto-commits changes after each query.

Methods

MethodDescription
Statement createStatement()Creates a Statement for running SQL.
Statement createStatement(int type, int concurrency)Creates a Statement whose ResultSets have the given type and concurrency (e.g. scrollable or updatable).
PreparedStatement prepareStatement(String sql)not in slidesCreates a PreparedStatement.
CallableStatement prepareCall(String sql)not in slidesCreates a CallableStatement.
void setAutoCommit(boolean status)Turns auto-commit on or off. It's true by default.
void commit()Makes all changes since the last commit or rollback permanent.
void rollback()Discards all changes since the last commit or rollback.
void close()Closes the connection and releases JDBC resources immediately.

10Statement Interface

Definition

Statement provides methods to execute queries against the database. It is a factory for ResultSet.

Methods

MethodDescription
ResultSet executeQuery(String sql)Runs a SELECT query and returns a ResultSet.
int executeUpdate(String sql)Runs CREATE, DROP, INSERT, UPDATE, DELETE and similar. Returns the number of rows affected.
boolean execute(String sql)Runs queries that may return multiple results.
int[] executeBatch()Runs a batch of commands.

Demo: insert / update / delete

import java.sql.*;

class FetchRecord {
    public static void main(String[] args) throws Exception {
        Class.forName("oracle.jdbc.driver.OracleDriver");
        Connection con = DriverManager.getConnection(
                "jdbc:oracle:thin:@localhost:1521:xe", "system", "oracle");
        Statement stmt = con.createStatement();

        // stmt.executeUpdate("insert into emp765 values(33,'Irfan',50000)");
        // stmt.executeUpdate("update emp765 set name='Vimal' where id=33");
        int result = stmt.executeUpdate("delete from emp765 where id=33");
        System.out.println(result + " records affected");

        con.close();
    }
}

11ResultSet Interface

Definition

A ResultSet object keeps a cursor pointing to one row of a table. At the start, the cursor is before the first row.

  • By default, it can only move forward and is not updatable.
  • To move both ways and allow updates, create the statement with:
Statement stmt = con.createStatement(
        ResultSet.TYPE_SCROLL_INSENSITIVE,   // or TYPE_SCROLL_SENSITIVE
        ResultSet.CONCUR_UPDATABLE);

Methods

MethodDescription
boolean next()Moves the cursor to the next row.
boolean previous()Moves the cursor to the previous row.
boolean first()Moves the cursor to the first row.
boolean last()Moves the cursor to the last row.
boolean absolute(int row)Moves the cursor to the given row number.
boolean relative(int row)Moves the cursor forward (+) or back (−) by that many rows.
int getInt(int columnIndex)Returns the column value (by index) as an int.
int getInt(String columnName)Returns the column value (by name) as an int.
String getString(int columnIndex)Returns the column value (by index) as a String.
String getString(String columnName)Returns the column value (by name) as a String.

Demo: read the 3rd row (scrollable ResultSet)

import java.sql.*;

class ScrollDemo {
    public static void main(String[] args) throws Exception {
        Class.forName("oracle.jdbc.driver.OracleDriver");
        Connection con = DriverManager.getConnection(
                "jdbc:oracle:thin:@localhost:1521:xe", "system", "oracle");
        Statement stmt = con.createStatement(
                ResultSet.TYPE_SCROLL_SENSITIVE, ResultSet.CONCUR_UPDATABLE);
        ResultSet rs = stmt.executeQuery("select * from emp765");

        rs.absolute(3);     // jump to row 3
        System.out.println(rs.getString(1) + " " + rs.getString(2) + " " + rs.getString(3));

        con.close();
    }
}

12PreparedStatement Interface

Definition

PreparedStatement is a sub-interface of Statement used to run parameterised queries. Values are written as ? and filled in later with setter methods.

String sql = "insert into emp values(?,?,?)";

Why use it?

  • Better performance: the query is compiled only once and can be run many times.
  • It also protects against SQL injection, because values are never pasted into the SQL text.

How to get it

public PreparedStatement prepareStatement(String query) throws SQLException // method of Connection

Methods

MethodDescription
void setInt(int paramIndex, int value)Sets an int value for parameter number paramIndex.
void setString(int paramIndex, String value)Sets a String value.
void setFloat(int paramIndex, float value)Sets a float value.
void setDouble(int paramIndex, double value)Sets a double value.
int executeUpdate()Runs CREATE, DROP, INSERT, UPDATE, DELETE and similar.
ResultSet executeQuery()Runs a SELECT and returns a ResultSet.

Demo: insert, update, delete, select

import java.sql.*;

class InsertPrepared {
    public static void main(String[] args) {
        try {
            Class.forName("oracle.jdbc.driver.OracleDriver");
            Connection con = DriverManager.getConnection(
                    "jdbc:oracle:thin:@localhost:1521:xe", "system", "oracle");

            // INSERT
            PreparedStatement ps = con.prepareStatement("insert into emp values(?,?)");
            ps.setInt(1, 101);            // 1st ?
            ps.setString(2, "Ratan");     // 2nd ?
            System.out.println(ps.executeUpdate() + " records inserted");

            // UPDATE
            ps = con.prepareStatement("update emp set name=? where id=?");
            ps.setString(1, "Sonoo");
            ps.setInt(2, 101);
            System.out.println(ps.executeUpdate() + " records updated");

            // SELECT
            ps = con.prepareStatement("select * from emp");
            ResultSet rs = ps.executeQuery();
            while (rs.next())
                System.out.println(rs.getInt(1) + " " + rs.getString(2));

            // DELETE
            ps = con.prepareStatement("delete from emp where id=?");
            ps.setInt(1, 101);
            System.out.println(ps.executeUpdate() + " records deleted");

            con.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }
}

13CallableStatement Interface

Definition

CallableStatement is used to call stored procedures and functions in the database.

  • It keeps business logic in the database. Procedures and functions are precompiled, which improves performance.
  • Example: a function that takes a date of birth and returns the employee's age.

Stored procedure vs function

Stored ProcedureFunction
Performs business logic.Performs a calculation.
Must not have a return type.Must have a return type.
May return 0 or more values.Returns only one value.
Can call functions.Can't call a procedure.
Supports input and output parameters.Supports only input parameters.
Can use try/catch exception handling.Can't use try/catch.

How to get it

public CallableStatement prepareCall("{call procedurename(?,?...?)}") // method of Connection

Methodsnot in slides

MethodDescription
void setInt / setString(int index, value)Sets the IN parameters.
void registerOutParameter(int index, int sqlType)Registers an OUT parameter and its type (e.g. Types.INTEGER).
boolean execute()Runs the call.
int getInt(int index)Reads an OUT or return value.

import java.sql.*;

public class Proc {
    public static void main(String[] args) throws Exception {
        Class.forName("oracle.jdbc.driver.OracleDriver");
        Connection con = DriverManager.getConnection(
                "jdbc:oracle:thin:@localhost:1521:xe", "system", "oracle");

        CallableStatement stmt = con.prepareCall("{call insertR(?,?)}");
        stmt.setInt(1, 1011);
        stmt.setString(2, "Amit");
        stmt.execute();
        System.out.println("success");
        con.close();
    }
}

Demo 2: call a function (returns a value)

-- SQL
create or replace function sum4(n1 in number, n2 in number) return number is
  temp number(8);
begin
  temp := n1 + n2;
  return temp;
end;
/

import java.sql.*;

public class FuncSum {
    public static void main(String[] args) throws Exception {
        Class.forName("oracle.jdbc.driver.OracleDriver");
        Connection con = DriverManager.getConnection(
                "jdbc:oracle:thin:@localhost:1521:xe", "system", "oracle");

        CallableStatement stmt = con.prepareCall("{?= call sum4(?,?)}");
        stmt.setInt(2, 10);
        stmt.setInt(3, 43);
        stmt.registerOutParameter(1, Types.INTEGER);   // the return value
        stmt.execute();
        System.out.println(stmt.getInt(1));            // Output: 53
        con.close();
    }
}

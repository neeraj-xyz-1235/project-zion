Unit 1.2: Swing Controls

Each control has a definition, its class declaration, its constructors, its methods and a small demo program you can run.

1JButton

Definition

JButton creates a labelled push button with a platform-independent implementation. Pushing the button triggers an action in the application.

  • It inherits the AbstractButton class, which provides features shared by all Swing buttons.
  • It can show text, an icon, or both.
  • You handle clicks with an ActionListener.

Demo: click the button to change a label

import javax.swing.*;

public class ButtonExample {
    public static void main(String[] args) {
        JFrame f = new JFrame("Button Example");
        JLabel l = new JLabel("Not clicked yet");
        l.setBounds(50, 50, 200, 30);

        JButton b = new JButton("Click Here");
        b.setBounds(50, 100, 120, 30);
        b.setToolTipText("Press me");
        b.addActionListener(e -> l.setText("Button clicked!"));

        f.add(l); f.add(b);
        f.setSize(300, 250);
        f.setLayout(null);
        f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        f.setVisible(true);
    }
}

2JLabel

Definition

JLabel places text or an image in a container. It displays a single line of read-only text: the program can change it, but the user can't edit it.

  • It inherits JComponent.
  • It's used to show static information or to caption other components (for example "Name:" beside a text field).

import javax.swing.*;
import java.awt.*;

public class LabelExample {

        JFrame f = new JFrame("Label Example");

        JLabel l1 = new JLabel("First Label.");

        JLabel l2 = new JLabel("Second Label.");

        f.setSize(300, 300);
        f.setLayout(null);
        f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        f.setVisible(true);
    }
}

3JTextField

Definition

JTextField is a text component that lets the user enter and edit a single line of text.

  • It inherits JTextComponent.
  • It's used in forms to read names, numbers, passwords (via JPasswordField) and similar input.
  • Pressing Enter inside the field fires an ActionEvent.

Demo: add two numbers

import javax.swing.*;

public class TextFieldExample {
    public static void main(String[] args) {
        JFrame f = new JFrame("TextField Example");

        JTextField t1 = new JTextField();
        t1.setBounds(50, 50, 150, 25);
        JTextField t2 = new JTextField();
        t2.setBounds(50, 90, 150, 25);
        JTextField result = new JTextField();
        result.setBounds(50, 130, 150, 25);
        result.setEditable(false);

        JButton add = new JButton("+");
        add.setBounds(50, 170, 60, 30);
        add.addActionListener(e -> {
            int a = Integer.parseInt(t1.getText());
            int b = Integer.parseInt(t2.getText());
            result.setText(String.valueOf(a + b));
        });

        f.add(t1); f.add(t2); f.add(result); f.add(add);
        f.setSize(300, 280);
        f.setLayout(null);
        f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        f.setVisible(true);
    }
}

4JTextArea

Definition

JTextArea is a multi-line area that displays text and lets the user edit it.

  • It inherits JTextComponent, so it gets the basic text-editing features, and adds features for multi-line text.
  • It's used in text editors, chat windows, comment boxes and address fields.
  • It doesn't scroll on its own. Put it inside a JScrollPane to get scroll bars.

Demo: word counter

import javax.swing.*;

public class TextAreaExample {
    public static void main(String[] args) {
        JFrame f = new JFrame("TextArea Example");

        JTextArea area = new JTextArea("Welcome to Swing");
        area.setBounds(10, 30, 260, 150);
        area.setLineWrap(true);
        area.setWrapStyleWord(true);

        JLabel count = new JLabel("Words: ?");
        count.setBounds(10, 190, 150, 25);

        JButton b = new JButton("Count");
        b.setBounds(170, 190, 100, 25);
        b.addActionListener(e -> {
            String text = area.getText().trim();
            int words = text.isEmpty() ? 0 : text.split("\\s+").length;
            count.setText("Words: " + words);
        });

        f.add(area); f.add(count); f.add(b);
        f.setSize(300, 280);
        f.setLayout(null);
        f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        f.setVisible(true);
    }
}

5JCheckBox

Definition

JCheckBox creates a checkbox that turns an option on (true) or off (false). Each click switches its state.

  • It inherits JToggleButton.
  • Checkboxes are independent of each other, so the user can tick several at once. Compare this with radio buttons.

Demo: food order

import javax.swing.*;

public class CheckBoxExample {
    public static void main(String[] args) {
        JFrame f = new JFrame("CheckBox Example");

        JCheckBox pizza = new JCheckBox("Pizza @ 100");
        pizza.setBounds(50, 50, 150, 25);
        JCheckBox burger = new JCheckBox("Burger @ 30", true);
        burger.setBounds(50, 80, 150, 25);

        JLabel total = new JLabel();
        total.setBounds(50, 150, 200, 25);

        JButton b = new JButton("Order");
        b.setBounds(50, 115, 100, 25);
        b.addActionListener(e -> {
            int amount = 0;
            if (pizza.isSelected())  amount += 100;
            if (burger.isSelected()) amount += 30;
            total.setText("Total: " + amount);
        });

        f.add(pizza); f.add(burger); f.add(b); f.add(total);
        f.setSize(300, 250);
        f.setLayout(null);
        f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        f.setVisible(true);
    }
}

import javax.swing.*;

public class RadioButtonExample {
    public static void main(String[] args) {
        JFrame f = new JFrame("RadioButton Example");

        JRadioButton r1 = new JRadioButton("Male");

}

11JMenuBar, JMenu and JMenuItem

Definition

  • JMenuBar displays a menu bar at the top of a window or frame. It can hold several menus.
  • JMenu is a pull-down menu shown from the menu bar (such as File or Edit). It inherits JMenuItem, so a menu can sit inside another menu as a submenu.
  • JMenuItem is a simple labelled item inside a menu (such as Open or Save). Every item in a menu must be a JMenuItem or one of its subclasses.

import javax.swing.*;

public class MenuExample {
    public static void main(String[] args) {
        JFrame f = new JFrame("Menu Example");

        JMenuBar mb = new JMenuBar();
        JMenu file = new JMenu("File");
        JMenu edit = new JMenu("Edit");
        JMenu submenu = new JMenu("Recent");

        JMenuItem open = new JMenuItem("Open");
        JMenuItem save = new JMenuItem("Save");
        JMenuItem exit = new JMenuItem("Exit");
        exit.addActionListener(e -> System.exit(0));

        submenu.add(new JMenuItem("notes.txt"));

        file.add(open);
        file.add(save);
        file.add(submenu);        // menu inside a menu
        file.addSeparator();
        file.add(exit);

        mb.add(file);
        mb.add(edit);
        f.setJMenuBar(mb);

        f.setSize(400, 300);
        f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        f.setVisible(true);
    }
}

import javax.swing.*;

public class ProgressBarExample {
    public static void main(String[] args) {
        JFrame f = new JFrame("ProgressBar Example");

        JProgressBar pb = new JProgressBar(0, 100);
        pb.setBounds(40, 40, 200, 30);
        pb.setValue(0);
        pb.setStringPainted(true);   // shows "45%"

        f.add(pb);
        f.setSize(300, 150);
        f.setLayout(null);
        f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        f.setVisible(true);

        // increase by 5 every 100 ms
        Timer t = new Timer(100, e -> {
            pb.setValue(pb.getValue() + 5);
            if (pb.getValue() == 100) ((Timer) e.getSource()).stop();
        });
        t.start();
    }
}

18JComponent

Definition

JComponent is the base class of all Swing components except the top-level containers.

  • Swing components whose names start with "J" descend from JComponent, for example JButton, JScrollPane, JPanel and JTable.
  • JFrame and JDialog do not inherit JComponent, because they are top-level containers. They extend AWT's Frame and Dialog.
  • JComponent extends Container, which extends Component. That's why every Swing component can hold other components.
  • It's an abstract class. You extend it to make your own custom component.

19JLayeredPane

Definition

JLayeredPane adds depth to a Swing container. It gives components a third dimension (z-order) and divides that depth into separate layers, so components on higher layers are drawn on top of lower ones.

  • It inherits JComponent.
  • Built-in layers, from bottom to top: DEFAULT_LAYER, PALETTE_LAYER, MODAL_LAYER, POPUP_LAYER, DRAG_LAYER.
  • Every JFrame already contains one, reachable with getLayeredPane().

import java.awt.*;

public class LayeredPaneExample extends JFrame {

        setSize(220, 220);
        JLayeredPane pane = getLayeredPane();

        JButton top = new JButton("Top");
        top.setBackground(Color.WHITE);
        top.setBounds(20, 20, 100, 100);

        JButton middle = new JButton("Middle");
        middle.setBackground(Color.RED);
        middle.setBounds(40, 40, 100, 100);

        JButton bottom = new JButton("Bottom");
        bottom.setBackground(Color.CYAN);
        bottom.setBounds(60, 60, 100, 100);

        pane.add(bottom, Integer.valueOf(1));   // lowest layer
        pane.add(middle, Integer.valueOf(2));
        pane.add(top,    Integer.valueOf(3));   // drawn on top

        setVisible(true);
    }

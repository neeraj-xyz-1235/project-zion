Advanced Java Programming: Notes

Built from the AJP unit PDFs. Each topic has a definition, then constructors, methods and a short demo program.

Unit 1.1 · Introduction to Swing

Swing, its features and applications, AWT vs Swing, JFC, the class hierarchy, Component methods, two ways to create a frame, AWT.

Unit 1.2 · Swing Controls

JButton, JLabel, JTextField, JTextArea, JCheckBox, JRadioButton, JComboBox, JTable, JList, JScrollBar, menus, JProgressBar, JTabbedPane, JDialog, JPanel, JFrame, JScrollPane, JComponent, JLayeredPane.

Unit 2.1 · Layout Managers

LayoutManager introduction, BorderLayout, FlowLayout, GridLayout, CardLayout.

Unit 2.2 · Event Handling

Events and their types, the delegation event model, EventObject, event classes, listeners, adapters, and programs for Action, Key, Mouse, Window, MouseMotion and Item events.

Unit 2.3 · JDBC

Introduction, the 4 driver types, 5 steps to connect, Oracle and MySQL examples, DriverManager, Connection, Statement, ResultSet, PreparedStatement, CallableStatement.

Unit 3.1 · Networking

IP, port, URL, MAC, sockets, protocols, TCP vs UDP, URL, URLConnection, InetAddress, DatagramSocket, ServerSocket and Socket, chat and concurrent server.

Unit 3.2 · RMI

RMI architecture, stub and skeleton, marshalling, registry, the Naming class, and the 6-step RMI example.

Labels used in these notes

not in slides means something was added from the Java API, either because the slide left it out or because the slide was an image that couldn't be read.

not in real Java means the slide lists it, but it doesn't exist in the JDK. Learn it for the exam if you must, but don't use it in code because it won't compile.

How to run a demo: save it as ClassName.java, then run javac ClassName.java and java ClassName.

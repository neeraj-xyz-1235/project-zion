Unit 2.1: Java Layout Managers

How Java arranges components inside a container automatically, so you don't have to position each one with setBounds().

1Layout Managers: Introduction

Definition

A LayoutManager arranges components in a container in a particular manner. It controls the position and size of every component in a GUI form.

Description

  • LayoutManager is an interface that every layout manager class implements.
  • You set one on a container with container.setLayout(new XyzLayout()).
  • setLayout(null) removes the layout manager. You then have to place everything yourself with setBounds(), as in Unit 1.
  • When the window is resized, the layout manager re-arranges the components automatically.

Layout manager classes

PackageClasses
java.awtBorderLayout, FlowLayout, GridLayout, CardLayout, GridBagLayout
javax.swingBoxLayout, GroupLayout, ScrollPaneLayout, SpringLayout

Default layouts

  • JFrame / Window / Dialog use BorderLayout by default.
  • JPanel / Applet use FlowLayout by default.

2BorderLayout

Definition

BorderLayout arranges components in five regions: NORTH, SOUTH, EAST, WEST and CENTER.

  • Each region can hold only one component.
  • It is the default layout of a frame or window.
  • CENTER takes all the space left over after the other four regions.
┌──────────────────────────┐ │ NORTH │ ├──────┬────────────┬──────┤ │ WEST │ CENTER │ EAST │ ├──────┴────────────┴──────┤ │ SOUTH │ └──────────────────────────┘

Fields (region constants)

FieldDescription
public static final String NORTHTop region.
public static final String SOUTHBottom region.
public static final String EASTRight region.
public static final String WESTLeft region.
public static final String CENTERMiddle region (the default when no region is given).
The slide lists these as int. In real Java they are String constants (for example NORTH = "North").

Constructors

ConstructorDescription
BorderLayout()Creates a border layout with no gaps between components.
BorderLayout(int hgap, int vgap)Creates a border layout with the given horizontal and vertical gaps.

Methodsnot in slides

MethodDescription
container.add(Component c, Object region)Adds a component to a region, e.g. f.add(b, BorderLayout.NORTH).
void setHgap(int hgap)Sets the horizontal gap.
void setVgap(int vgap)Sets the vertical gap.

Without specifying a region

If you call add() without a region, every component goes to CENTER. Each one replaces the last, so only the last component added is shown and it covers the whole area. Gaps have no effect in that case.

Demo

import java.awt.*;
import javax.swing.*;

public class Border {
    public static void main(String[] args) {
        JFrame f = new JFrame("BorderLayout");
        f.setLayout(new BorderLayout(20, 15));   // hgap 20, vgap 15

        f.add(new JButton("NORTH"),  BorderLayout.NORTH);
        f.add(new JButton("SOUTH"),  BorderLayout.SOUTH);
        f.add(new JButton("EAST"),   BorderLayout.EAST);
        f.add(new JButton("WEST"),   BorderLayout.WEST);
        f.add(new JButton("CENTER"), BorderLayout.CENTER);

        f.setSize(300, 300);
        f.setVisible(true);
    }
}

3FlowLayout

Definition

FlowLayout arranges components in a line, one after another (in a flow), like words in a sentence. When a row is full, the next component wraps to a new row.

  • It is the default layout of a panel or applet.
  • Components keep their preferred size. They are not stretched.

Fields

FieldDescription
public static final int LEFTEach row is left-aligned.
public static final int RIGHTEach row is right-aligned.
public static final int CENTEREach row is centred (the default).
public static final int LEADINGAligned to the leading edge of the container's orientation.
public static final int TRAILINGAligned to the trailing edge of the container's orientation.

Constructors

ConstructorDescription
FlowLayout()Centre alignment, with default 5-unit horizontal and vertical gaps.
FlowLayout(int align)The given alignment, with default 5-unit gaps.
FlowLayout(int align, int hgap, int vgap)The given alignment and gaps.

Methodsnot in slides

MethodDescription
void setAlignment(int align)Changes the alignment.
int getAlignment()Returns the alignment.
void setHgap(int) / setVgap(int)Changes the gaps.

Demo

import java.awt.*;
import javax.swing.*;

public class MyFlowLayout {
    public static void main(String[] args) {
        JFrame f = new JFrame("FlowLayout");
        f.setLayout(new FlowLayout(FlowLayout.LEFT, 20, 25));  // left, hgap 20, vgap 25

        for (int i = 1; i <= 10; i++) {
            f.add(new JButton("" + i));
        }

        f.setSize(300, 300);
        f.setVisible(true);
    }
}

4GridLayout

Definition

GridLayout arranges components in a rectangular grid of rows and columns. One component goes in each cell, and all cells are the same size.

  • Components are filled in left to right, then top to bottom.
  • Each component stretches to fill its cell.

Constructors

ConstructorDescription
GridLayout()One row, with one column per component.
GridLayout(int rows, int columns)The given rows and columns, with no gaps.
GridLayout(int rows, int columns, int hgap, int vgap)The given rows and columns, plus gaps.

Methodsnot in slides

MethodDescription
void setRows(int rows)Sets the number of rows.
void setColumns(int cols)Sets the number of columns.
void setHgap(int) / setVgap(int)Sets the gaps.

Demo: a 3 × 3 grid

import java.awt.*;
import javax.swing.*;

public class MyGridLayout {
    public static void main(String[] args) {
        JFrame f = new JFrame("GridLayout");
        f.setLayout(new GridLayout(3, 3, 20, 25));   // 3 rows, 3 cols, gaps

        for (int i = 1; i <= 9; i++) {
            f.add(new JButton("" + i));
        }

        f.setSize(300, 300);
        f.setVisible(true);
    }
}

5CardLayout

Definition

CardLayout manages components so that only one component is visible at a time. It treats each component as a card in a deck, which is where the name comes from.

  • Each card is added with a name: container.add("name", component).
  • It's used for wizards (Next/Back screens), slideshows and tab-like screens.

Constructors

ConstructorDescription
CardLayout()Creates a card layout with zero horizontal and vertical gaps.
CardLayout(int hgap, int vgap)Creates a card layout with the given gaps.

Methods

MethodDescription
public void next(Container parent)Flips to the next card. After the last card, it goes back to the first.
public void previous(Container parent)Flips to the previous card.
public void first(Container parent)Flips to the first card.
public void last(Container parent)Flips to the last card.
public void show(Container parent, String name)Flips to the card with the given name.

Demo: click to see the next card

import java.awt.*;
import java.awt.event.*;
import javax.swing.*;

public class CardLayoutExample extends JFrame implements ActionListener {
    CardLayout card;
    Container c;

    CardLayoutExample() {
        c = getContentPane();
        card = new CardLayout(40, 30);
        c.setLayout(card);

        JButton b1 = new JButton("Apple");
        JButton b2 = new JButton("Boy");
        JButton b3 = new JButton("Cat");
        b1.addActionListener(this);
        b2.addActionListener(this);
        b3.addActionListener(this);

        c.add("a", b1);     // each button is one card
        c.add("b", b2);
        c.add("c", b3);
    }

    public void actionPerformed(ActionEvent e) {
        card.next(c);       // show the next card
    }

    public static void main(String[] args) {
        CardLayoutExample cl = new CardLayoutExample();
        cl.setSize(400, 400);
        cl.setVisible(true);
        cl.setDefaultCloseOperation(EXIT_ON_CLOSE);
    }
}

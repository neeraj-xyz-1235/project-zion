Unit 1.1: Introduction to Swing

The theory behind Swing: what it is, why it replaced AWT, how its classes are arranged, and how to open your first window.

1Swing

Definition

Java Swing is a GUI (Graphical User Interface) toolkit that is part of the Java Foundation Classes (JFC). You use it to build window-based desktop applications.

Description

  • Swing was introduced in the late 1990s to fix the limitations of the older AWT (Abstract Window Toolkit).
  • It is built on top of AWT but is written entirely in Java. It doesn't rely on the operating system's native components, so an app looks the same on Windows, Linux and macOS.
  • It provides a full set of components: buttons, text fields, panels, tables, trees, menus and more. All of them can be customised.
  • All Swing classes live in the javax.swing package, for example JButton, JTextField, JCheckBox and JMenu.
  • Swing component names start with J, which separates them from the AWT versions (Button vs JButton).

2Features of Swing

FeatureDescription
Platform independenceA Swing app runs on any platform that supports Java, with no code changes.
Rich set of componentsRanges from basic components (buttons, labels) to advanced ones (tables, trees, scroll panes, colour chooser, tabbed pane).
CustomizabilityYou can change the size, colour, font, border, layout and behaviour of every component.
Event handlingA robust event model lets the program respond to user actions such as button clicks, key presses and mouse movement.
Layout managersLayout managers (FlowLayout, BorderLayout, GridLayout…) arrange and resize components automatically as the window size changes.
LightweightSwing draws its own components, so they don't need a native OS peer.
Pluggable look and feelThe appearance (theme) can be changed at runtime without changing the code.
MVC architectureComponents separate data (Model), display (View) and control logic (Controller).

3Applications of Java Swing

  • Desktop applications: Swing suits apps that need a rich, responsive UI, such as IDEs (NetBeans is built with Swing), productivity tools and media players.
  • Legacy systems: many enterprise applications built with Swing are still in use. Swing gives a stable base for maintaining and extending them.
  • Educational purposes: Swing is simple and versatile, so it's widely used to teach GUI programming concepts to beginners.

5JFC (Java Foundation Classes)

Definition

The Java Foundation Classes (JFC) are a set of GUI components and services that simplify building desktop applications.

Parts of JFC

  • Swing components: the GUI widgets (JButton, JTable…)
  • AWT: the base windowing toolkit Swing is built on
  • Pluggable look and feel: changeable themes
  • Java 2D: advanced 2D graphics and imaging
  • Accessibility API: support for screen readers and similar tools
  • Drag and drop: moving data between applications

Swing is the best-known part of JFC, which is why the two terms are often used together.

6Hierarchy of Java Swing Classes

Every Swing component ultimately inherits from AWT's Component class. Top-level windows (JFrame, JDialog) extend AWT windows. All other components extend JComponent.

7Commonly Used Methods of the Component Class

These methods come from java.awt.Component, so every AWT and Swing component has them.

MethodDescription
public void add(Component c)Adds a component onto another component (container).
public void setSize(int width, int height)Sets the size of the component.
public void setLayout(LayoutManager m)Sets the layout manager for the component.
public void setVisible(boolean b)Shows or hides the component. It is false by default.
public void setBounds(int x, int y, int w, int h)not in slidesSets position and size together. Used with setLayout(null).

Demo

import javax.swing.*;

public class ComponentDemo {
    public static void main(String[] args) {
        JFrame f = new JFrame("Component Methods");
        JButton b = new JButton("OK");
        b.setBounds(100, 80, 80, 30);   // position + size
        f.add(b);                       // add()
        f.setSize(300, 200);            // setSize()
        f.setLayout(null);              // setLayout()
        f.setVisible(true);             // setVisible()
    }
}

8Java Swing Examples: Two Ways to Create a Frame

A frame is the main window of a Swing application. You can create one in two ways, and you can write the code inside main(), a constructor or any other method.

Way 1: By creating an object of the JFrame class (Association)

Your class has a JFrame. You create it with new JFrame() and call methods on that object.

import javax.swing.*;

public class FirstSwingExample {
    public static void main(String[] args) {
        JFrame f = new JFrame();            // create frame object
        JButton b = new JButton("click");   // create button
        b.setBounds(130, 100, 100, 40);     // x, y, width, height
        f.add(b);                           // add button to frame
        f.setSize(400, 500);
        f.setLayout(null);                  // no layout manager
        f.setVisible(true);
    }
}

Way 1b: Association inside a constructor

The same code moved into the class constructor. main() just creates an object of the class.

import javax.swing.*;

public class Simple {
    JFrame f;

    Simple() {
        f = new JFrame();
        JButton b = new JButton("click");
        b.setBounds(130, 100, 100, 40);
        f.add(b);
        f.setSize(400, 500);
        f.setLayout(null);
        f.setVisible(true);
    }

    public static void main(String[] args) {
        new Simple();
    }
}

Way 2: By extending the JFrame class (Inheritance)

Your class is a JFrame. You don't create a JFrame object yourself, and you call add(), setSize() and the rest directly.

import javax.swing.*;

public class Simple2 extends JFrame {
    Simple2() {
        JButton b = new JButton("click");
        b.setBounds(130, 100, 100, 40);
        add(b);                 // no "f." needed: this class IS the frame
        setSize(400, 500);
        setLayout(null);
        setVisible(true);
    }

    public static void main(String[] args) {
        new Simple2();
    }
}

9Java AWT

Definition

AWT (Abstract Window Toolkit) is Java's original API for building GUI and window-based applications. Its classes are in the java.awt package.

Description

  • It provides GUI classes such as Label, Button, TextField, Checkbox and Menu.
  • It is heavyweight: each component uses a native component of the operating system.
  • It is platform-dependent: the same AWT program can look different on Windows, Linux and macOS.

AWT Hierarchy

Object └── Component ├── Button ├── Label ├── Checkbox ├── Choice ├── List ├── Scrollbar ├── Canvas ├── TextComponent │ ├── TextField │ └── TextArea └── Container ├── Window │ ├── Frame │ └── Dialog └── Panel └── Applet

AWT Example (from slides, a simple form)

import java.awt.*;

public class AwtApp extends Frame {
    AwtApp() {
        Label firstName = new Label("First Name");
        firstName.setBounds(20, 50, 80, 20);
        Label lastName = new Label("Last Name");
        lastName.setBounds(20, 80, 80, 20);

        TextField firstNameTF = new TextField();
        firstNameTF.setBounds(120, 50, 100, 20);
        TextField lastNameTF = new TextField();
        lastNameTF.setBounds(120, 80, 100, 20);

        Button sbmt = new Button("Submit");
        sbmt.setBounds(20, 160, 100, 30);
        Button reset = new Button("Reset");
        reset.setBounds(120, 160, 100, 30);

        add(firstName); add(lastName);
        add(firstNameTF); add(lastNameTF);
        add(sbmt); add(reset);

        setSize(300, 300);
        setLayout(null);
        setVisible(true);
    }

    public static void main(String[] args) {
        new AwtApp();
    }
}

The same form in Swing

The only changes are the javax.swing import and the J prefix on each class.

import javax.swing.*;

public class SwingApp {
    SwingApp() {
        JFrame f = new JFrame();

        JLabel firstName = new JLabel("First Name");
        firstName.setBounds(20, 50, 80, 20);
        JTextField firstNameTF = new JTextField();
        firstNameTF.setBounds(120, 50, 100, 20);

        JButton sbmt = new JButton("Submit");
        sbmt.setBounds(20, 160, 100, 30);
        JButton reset = new JButton("Reset");
        reset.setBounds(120, 160, 100, 30);

        f.add(firstName); f.add(firstNameTF);
        f.add(sbmt); f.add(reset);

        f.setSize(300, 300);
        f.setLayout(null);
        f.setVisible(true);
    }

    public static void main(String[] args) {
        new SwingApp();
    }
}
An AWT Frame doesn't close when you click X unless you add a WindowListener. In Swing, call f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE).

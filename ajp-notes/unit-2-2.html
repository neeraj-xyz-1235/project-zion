Unit 2.2: Event Handling

How a Swing program notices user actions (clicks, keys, mouse moves) and responds to them.

1What is an Event?

Definition

An event is a change in the state of an object. It describes the change in the state of the source.

Description

Events are generated when the user interacts with GUI components. Examples:

  • clicking a button
  • moving the mouse
  • typing a character on the keyboard
  • selecting an item from a list
  • scrolling the page

2Types of Event

Foreground eventsBackground events
Need direct interaction from the user.Don't need any user interaction.
Generated when a person interacts with GUI components.Generated by the system.
E.g. button click, mouse move, key press, list selection, scrolling.E.g. OS interrupts, hardware or software failure, timer expiry, operation completion.
The slide says background events "require the interaction of the end user". That's a typo: background events don't require user interaction.

3Event Handling & the Delegation Event Model

Definition

Event handling is the mechanism that controls an event and decides what should happen when it occurs. The code that runs is called the event handler.

Java handles events with the Delegation Event Model, which defines the standard way events are generated and handled.

Key participants

ParticipantRole
SourceThe object the event happens on (e.g. a JButton). It passes information about the event to its handler.
Listener (event handler)An object that responds to the event. It waits until it receives an event, processes it, then returns.

Why "delegation"?

  • The UI component delegates processing of the event to a separate piece of code (the listener).
  • This separates UI logic from the logic that handles the event.
  • The listener must be registered with the source, e.g. button.addActionListener(listener).
  • It's efficient: notifications go only to the listeners that registered for them.
[ Source ] ──event object──▶ [ Listener ] (JButton) (actionPerformed runs) ▲ │ └──── registered via addXxxListener()

4Steps Involved in Event Handling

  1. The user clicks the button and the event is generated.
  2. An object of the matching event class is created automatically, holding information about the source and the event.
  3. The event object is forwarded to the method of the registered listener.
  4. That method executes and returns.

In code, you need to:

  1. Implement the listener interface (e.g. implements ActionListener).
  2. Register it with the source (b.addActionListener(this)).
  3. Write the handler method (public void actionPerformed(ActionEvent e) {...}).

5EventObject Class

Definition

EventObject is the root class of all event objects. Every event is built with a reference to its source, the object the event first happened on. It is in the java.util package.

Class declaration

7Event Listeners

Definition

Event listeners are interfaces responsible for handling events. Each listener method takes one argument, an object of a subclass of EventObject. For example, mouse listener methods receive a MouseEvent.

EventListener interface

  • A marker interface (it has no methods) that every listener interface must extend.
  • It is in the java.util package.

8Event Adapters

Definition

Adapters are abstract classes that implement a listener interface with empty methods. They exist as a convenience for creating listener objects.

Why use them?

An interface such as WindowListener has 7 methods, and you must write all 7 even if you only need one. If you extend WindowAdapter instead, you override only the methods you need.

Swing adapters

AdapterFor listener
FocusAdapterFocusListener: receives focus events
KeyAdapterKeyListener: receives key events
MouseAdapterMouseListener: receives mouse events
MouseMotionAdapterMouseMotionListener: receives mouse motion events
WindowAdapterWindowListener: receives window events
ActionListener and ItemListener have no adapter, because each has only one method.

Demo: override just one method

import javax.swing.*;
import java.awt.event.*;

public class AdapterExample {
    public static void main(String[] args) {
        JFrame f = new JFrame("Adapter Example");
        f.addWindowListener(new WindowAdapter() {
            public void windowClosing(WindowEvent e) {   // only this one
                System.out.println("Bye!");
                System.exit(0);
            }
        });
        f.setSize(300, 200);
        f.setVisible(true);
    }
}

9Program: ActionEvent

ActionEvent is generated when a button is clicked, Enter is pressed in a text field, or a menu item is chosen. It is handled by ActionListener.

MethodDescription
void actionPerformed(ActionEvent e)Called when the action happens.
Object e.getSource()Which component fired the event.
String e.getActionCommand()not in slidesThe button's text / command string.
import javax.swing.*;
import java.awt.event.*;

public class ActionEventExample extends JFrame implements ActionListener {
    JButton b;
    JLabel l;
    int count = 0;

    ActionEventExample() {
        b = new JButton("Click Me!");
        b.setBounds(90, 50, 100, 30);
        b.addActionListener(this);          // register listener

        l = new JLabel("Button not clicked yet.");
        l.setBounds(50, 100, 200, 20);

        add(b); add(l);
        setSize(300, 200);
        setLayout(null);
        setVisible(true);
    }

    public void actionPerformed(ActionEvent e) {
        count++;
        l.setText("Button clicked " + count + " times!");
    }

    public static void main(String[] args) {
        new ActionEventExample();
    }
}

10Program: KeyEvent

KeyEvent is generated when a key is pressed, released or typed. It is handled by KeyListener (or KeyAdapter).

MethodDescription
void keyPressed(KeyEvent e)A key is pressed down.
void keyReleased(KeyEvent e)A key is released.
void keyTyped(KeyEvent e)A key is pressed and released, producing a character.
char e.getKeyChar()The character typed.
int e.getKeyCode()The key's code (e.g. KeyEvent.VK_ENTER).
static String KeyEvent.getKeyText(int code)The key's name, e.g. "Enter".
import javax.swing.*;
import java.awt.*;
import java.awt.event.*;

public class KeyEventExample extends JFrame implements KeyListener {
    JTextArea area;
    JLabel status;

    KeyEventExample() {
        area = new JTextArea();
        area.addKeyListener(this);
        status = new JLabel("Press a key in the text area...");

        add(area, BorderLayout.CENTER);
        add(status, BorderLayout.SOUTH);
        setSize(400, 300);
        setVisible(true);
    }

    public void keyPressed(KeyEvent e) {
        status.setText("Key Pressed: " + KeyEvent.getKeyText(e.getKeyCode()));
    }
    public void keyReleased(KeyEvent e) {
        status.setText("Key Released: " + KeyEvent.getKeyText(e.getKeyCode()));
    }
    public void keyTyped(KeyEvent e) {
        status.setText("Key Typed: " + e.getKeyChar());
    }

    public static void main(String[] args) {
        new KeyEventExample();
    }
}

11Program: MouseEvent

MouseEvent is generated by a mouse action in a component. Clicks, presses, releases, enters and exits are handled by MouseListener (or MouseAdapter).

MethodDescription
void mouseClicked(MouseEvent e)The button is pressed and released.
void mousePressed(MouseEvent e)The button is pressed down.
void mouseReleased(MouseEvent e)The button is released.
void mouseEntered(MouseEvent e)The cursor enters the component.
void mouseExited(MouseEvent e)The cursor leaves the component.
int e.getX() / e.getY()The position of the mouse.
int e.getButton()Which mouse button was used.
import javax.swing.*;
import java.awt.*;
import java.awt.event.*;

public class MouseEventExample {
    public static void main(String[] args) {
        JFrame f = new JFrame("MouseEvent Example");
        JPanel panel = new JPanel();
        JLabel status = new JLabel("No mouse event yet.");

        panel.addMouseListener(new MouseAdapter() {
            public void mouseClicked(MouseEvent e) {
                status.setText("Clicked at X: " + e.getX() + ", Y: " + e.getY());
            }
            public void mouseEntered(MouseEvent e) {
                status.setText("Mouse entered!");
            }
            public void mouseExited(MouseEvent e) {
                status.setText("Mouse exited!");
            }
        });

        f.add(panel, BorderLayout.CENTER);
        f.add(status, BorderLayout.SOUTH);
        f.setSize(400, 300);
        f.setVisible(true);
    }
}

12Program: WindowEvent

WindowEvent represents a change in the state of a window. It is handled by WindowListener, which has 7 methods, all of which must be implemented (or use WindowAdapter).

MethodCalled when
windowOpened(WindowEvent e)The window is first shown.
windowClosing(WindowEvent e)The user clicks X (before closing).
windowClosed(WindowEvent e)The window has been closed.
windowIconified(WindowEvent e)The window is minimised.
windowDeiconified(WindowEvent e)The window is restored.
windowActivated(WindowEvent e)The window gains focus.
windowDeactivated(WindowEvent e)The window loses focus.
import javax.swing.*;
import java.awt.event.*;

public class WindowEventExample extends JFrame implements WindowListener {
    WindowEventExample() {
        super("WindowEvent Example");
        addWindowListener(this);
        add(new JLabel("Watch the console for window events!"));
        setSize(400, 300);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setVisible(true);
    }

    public void windowOpened(WindowEvent e)      { System.out.println("Window opened"); }
    public void windowClosing(WindowEvent e)     { System.out.println("Window closing..."); }
    public void windowClosed(WindowEvent e)      { System.out.println("Window closed"); }
    public void windowIconified(WindowEvent e)   { System.out.println("Minimized"); }
    public void windowDeiconified(WindowEvent e) { System.out.println("Restored"); }
    public void windowActivated(WindowEvent e)   { System.out.println("Gained focus"); }
    public void windowDeactivated(WindowEvent e) { System.out.println("Lost focus"); }

    public static void main(String[] args) {
        new WindowEventExample();
    }
}

13Program: Mouse Motion Event

Mouse movement (with or without a button held down) is handled by MouseMotionListener. It receives MouseEvent objects.

MethodCalled when
void mouseMoved(MouseEvent e)The mouse moves with no button pressed.
void mouseDragged(MouseEvent e)The mouse moves with a button held down.
import javax.swing.*;
import java.awt.*;
import java.awt.event.*;

public class MouseMotionEventExample extends JFrame implements MouseMotionListener {
    JLabel status;

    MouseMotionEventExample() {
        JPanel panel = new JPanel();
        panel.setBackground(Color.LIGHT_GRAY);
        panel.addMouseMotionListener(this);

        status = new JLabel("Move or drag the mouse over the panel.");
        add(panel, BorderLayout.CENTER);
        add(status, BorderLayout.SOUTH);
        setSize(400, 300);
        setVisible(true);
    }

    public void mouseMoved(MouseEvent e) {
        status.setText("Moved at: (" + e.getX() + ", " + e.getY() + ")");
    }
    public void mouseDragged(MouseEvent e) {
        status.setText("Dragged at: (" + e.getX() + ", " + e.getY() + ")");
    }

    public static void main(String[] args) {
        new MouseMotionEventExample();
    }
}

14Program: ItemEvent

ItemEvent is generated when an item is selected or deselected in a JCheckBox, JRadioButton or JComboBox. It is handled by ItemListener.

MethodDescription
void itemStateChanged(ItemEvent e)Called when an item's state changes.
int e.getStateChange()Returns ItemEvent.SELECTED or ItemEvent.DESELECTED.
Object e.getSource()Which checkbox fired the event.
import javax.swing.*;
import java.awt.*;
import java.awt.event.*;

public class ItemEventExample extends JFrame implements ItemListener {
    JCheckBox c1, c2;
    JLabel status;

    ItemEventExample() {
        c1 = new JCheckBox("Option A");
        c2 = new JCheckBox("Option B");
        status = new JLabel("No options selected.");
        c1.addItemListener(this);
        c2.addItemListener(this);

        setLayout(new FlowLayout());
        add(c1); add(c2); add(status);
        setSize(300, 150);
        setVisible(true);
    }

    public void itemStateChanged(ItemEvent e) {
        JCheckBox src = (JCheckBox) e.getSource();
        if (e.getStateChange() == ItemEvent.SELECTED)
            status.setText(src.getText() + " selected.");
        else
            status.setText(src.getText() + " deselected.");
    }

    public static void main(String[] args) {
        new ItemEventExample();
    }
}
